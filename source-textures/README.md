# Source Textures

Arquivos de origem em formato **Affinity Designer** (.af) utilizados para gerar as texturas e materiais gráficos do mod The Ark.

## Estrutura

| Arquivo | Descrição |
| --------- | ----------- |
| `chapter_1.af` | Texturas do Capítulo 1 |
| `chapter_2.af` | Texturas do Capítulo 2 |
| `chapter_3.af` | Texturas do Capítulo 3 |
| `chapter_4.af` | Texturas do Capítulo 4 |
| `chapter_5.af` | Texturas do Capítulo 5 |
| `epilogue_1.af` | Texturas do Epílogo 1 |
| `epilogue_2.af` | Texturas do Epílogo 2 |
| `epilogue_3.af` | Texturas do Epílogo 3 |

## Fluxo de Trabalho

1. Cada arquivo `.af` contém os layouts e texturas origem.
2. As texturas exportadas são utilizadas pelo jogo como overlays e documentos.
3. Esses arquivos servem como backup para referência visual e edições futuras.

## Software

**[Affinity Designer](https://www.affinity.studio/pt_br/download)**

## Observações

- Arquivos `.af` não são lidos pelo jogo diretamente; são apenas a fonte editável.
- Para texturas usadas em runtime, consultar os arquivos exportados em `media/textures/`.
